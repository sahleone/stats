# Interpretation
The test does not yield a single confidence interval; instead, examine standardized residuals or compute difference in proportions for each 2×2 slice.

# Effect Size
Report Cramér’s V:
- 0.10 small, 0.30 medium, 0.50 large (for df=1; adjust heuristics for larger tables).
