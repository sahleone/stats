# Formula
$$ \hat{p} \pm z_{\alpha/2} \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}} $$

# Example
p̂ = 0.66, n = 200, 95% CI = 0.66 ± 1.960·√(0.66·0.34/200) ⇒ (0.59, 0.73).

# Interpretation
If p₀ lies outside the CI, a two-tailed test at α = 0.05 would reject H₀.
