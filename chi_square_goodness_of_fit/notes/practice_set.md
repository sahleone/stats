# Problems
1. Candy color counts vs expected 20% each (5 colors). Use α=0.05.
2. Traffic accidents by weekday vs uniform distribution (7 days). α=0.01.
3. Survey responses vs expected 40/35/25%. α=0.05; identify categories causing deviation.
4. Fruit defects expected 10% bruised, 5% rotten, 85% clean. Sample n=300; test α=0.05.

# Solutions (sketch)
1. Compute E = total/5, χ² ≤ critical? (fill with actual numbers when available).
2. Use df=6; reject if χ² > χ²_{0.01,6}.
3. Calculate standardized residuals to find categories with largest |O−E|/√E.
4. Similar steps.
