# Formula
Use the known σ to build the CI:
$$ \bar{x} \pm z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}} $$

# Example
Battery sample: x̄ = 9.6, σ = 1.2, n = 36, 95% CI → 9.6 ± 1.960·1.2/√36 = 9.6 ± 0.392 = (9.208, 9.992).

# Interpretation
“We are 95% confident that the true mean battery life lies between 9.21 and 9.99 hours.” If μ₀ falls outside this interval, the two-tailed z-test at α = 0.05 would reject H₀.

# Tips
- Use one-sided z critical values if reporting one-sided bounds.
- Mention σ is known when citing the interval.
