# Instructions
Complete each problem before reading the solutions. Assume all conditions for the z-test are met and use the given σ values.

# Problems
1. **Credit Card Spending.** Historical average monthly spending is $520 with σ = $60. A sample of 49 customers averages $538. Test at α = 0.05 whether spending changed.
2. **Lab Temperature.** A process requires mean temperature 68°F with σ = 1.5°F. Twelve automated readings (n = 36) average 67.2°F. Test if the mean dropped (left-tailed) at α = 0.01.
3. **Delivery Time.** Delivery times historically average 2.4 days with σ = 0.5 days. A new carrier’s 30 orders average 2.2 days. Test if the mean decreased at α = 0.05 and report the 95% CI.
4. **Exam Scores.** Previous exam average was 78 with σ = 10. This term’s 64 students average 80.7. Test if performance improved (right-tailed) at α = 0.10 and compute effect size.

# Solutions
1. z = (538 − 520)/(60/√49) = 2.10; p ≈ 0.036 < 0.05 ⇒ reject H₀, evidence of change.
2. z = (67.2 − 68)/(1.5/√36) = −3.20; p ≈ 0.0007 ⇒ reject H₀, mean decreased.
3. z = (2.2 − 2.4)/(0.5/√30) ≈ −2.19; p ≈ 0.014 < 0.05 ⇒ reject H₀; 95% CI = 2.2 ± 1.960·0.5/√30 ≈ (2.02, 2.38).
4. z = (80.7 − 78)/(10/√64) = 2.16; p ≈ 0.015 < 0.10 ⇒ reject H₀; effect size d = (80.7 − 78)/10 = 0.27 (small-to-medium).
