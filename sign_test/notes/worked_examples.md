# Example: Weight-Loss Program
10 participants show differences (after − before). After removing 1 tie, n = 9 with 8 positives. Test H₀: median diff = 0 at α = 0.05 (right-tailed).

- p = P(X ≥ 8) with X ~ Bin(9,0.5) = P(X=8)+P(X=9) = 0.0195.
- Since p < 0.05, reject H₀; median decrease > 0.
