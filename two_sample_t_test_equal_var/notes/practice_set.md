# Problems
1. **Fuel Efficiency.** Car Model A (n₁=16) mean=32.1 mpg, s₁=2.4; Model B (n₂=15) mean=29.8 mpg, s₂=2.7. Test at α=0.05 if means differ.
2. **Heart Rate Training.** Program X (n₁=10) mean reduction=7.2 bpm, s₁=1.5; Program Y (n₂=12) mean reduction=5.9 bpm, s₂=1.7. Test right-tailed α=0.05.
3. **Plant Height.** Fertilizer A (n₁=20) mean=54 cm, s₁=4.8; Fertilizer B (n₂=18) mean=52 cm, s₂=5.1. Test at α=0.10 and report 90% CI.
4. **Customer Satisfaction.** Store 1 (n₁=25) mean=8.6, s₁=0.9; Store 2 (n₂=25) mean=8.2, s₂=1.1. Test at α=0.01, compute effect size.

# Solutions
1. sₚ ≈ 2.55, t ≈ 2.87, df=29 ⇒ reject H₀; CI ≈ (0.7, 3.8) mpg.
2. sₚ ≈ 1.61, t ≈ 2.08, df=20 ⇒ p≈0.025 < 0.05 ⇒ reject H₀; Program X better.
3. sₚ ≈ 4.95, t ≈ 1.33, df=36 ⇒ p≈0.19 > 0.10 ⇒ fail to reject; 90% CI includes 0.
4. sₚ ≈ 1.00, t ≈ 1.57, df=48 ⇒ p≈0.12 > 0.01 ⇒ fail to reject; d ≈ 0.40.
