# Example 1: Scores
σ₁ = 5, σ₂ = 6, n₁ = 40, n₂ = 35, x̄₁ = 82, x̄₂ = 78, α = 0.05 two-tailed.

- z = (82 − 78)/√(5²/40 + 6²/35) ≈ 3.02.
- Critical z = ±1.960 ⇒ reject H₀.
- 95% CI: 4 ± 1.960·√(5²/40 + 6²/35) ⇒ (1.4, 6.6).

# Example 2: Production Output (Right-Tailed)
σ₁ = 3.2, σ₂ = 2.9, n₁ = 30, n₂ = 32, x̄₁ = 105, x̄₂ = 100, α = 0.01 right-tailed.

- z = (105 − 100)/√(3.2²/30 + 2.9²/32) ≈ 6.03.
- Critical z(0.01) = 2.326 ⇒ reject H₀.
- Effect size d ≈ (5)/√((3.2² + 2.9²)/2) ≈ 1.65.
