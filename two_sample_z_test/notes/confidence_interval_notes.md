# Formula
$$ (\bar{x}_1 - \bar{x}_2) \pm z_{\alpha/2} \sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}} $$

# Example
Scores example: difference = 4, SE = √(5²/40 + 6²/35) ≈ 1.32, 95% CI = 4 ± 1.960·1.32 ⇒ (1.4, 6.6).

# Interpretation
If 0 is outside the CI, the two-tailed test at α = 0.05 rejects H₀.
