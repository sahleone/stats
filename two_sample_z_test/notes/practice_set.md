# Problems
1. σ1=4, σ2=5, n1=36, n2=30, x̄1=58, x̄2=55. Test α=0.05.
2. σ1=2.5, σ2=3, n1=25, n2=25, x̄1=120, x̄2=118. Test α=0.10 right-tailed.
3. σ1=8, σ2=7, n1=50, n2=45, x̄1=210, x̄2=205. Test α=0.01.
4. σ1=1.8, σ2=1.6, n1=40, n2=40, x̄1=32.5, x̄2=31.8. Test α=0.05 and report CI.

# Solutions
1. z≈2.18 ⇒ reject.
2. z≈1.89 ⇒ p≈0.029 <0.10 ⇒ reject.
3. z≈2.71 ⇒ reject at 0.01.
4. z≈2.21 ⇒ reject; 95% CI ≈ (0.1, 1.3).
