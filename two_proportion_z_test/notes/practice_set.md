# Problems
1. x1=110, n1=220; x2=95, n2=210. Test α=0.05.
2. x1=25, n1=60; x2=18, n2=55. Test α=0.10 right-tailed.
3. x1=150, n1=250; x2=120, n2=240. Test α=0.01 two-tailed; report CI.
4. x1=40, n1=80; x2=20, n2=70. Test α=0.05 left-tailed (p1 < p2?).

# Solutions
1. z≈1.38 ⇒ fail to reject.
2. z≈1.17 ⇒ p≈0.12 >0.10 ⇒ fail to reject.
3. z≈2.60 ⇒ reject; 99% CI excludes 0.
4. z≈−2.00 ⇒ reject at 0.05 (left-tailed).
